# Canva Pro Landing Page

🎨 A stunning, fully responsive landing page for Canva Pro with interactive features and client-side backend.

## 🌐 Live Demo

Visit: [https://islamosbett.github.io/canva-pro-landing](https://islamosbett.github.io/canva-pro-landing)

## ✨ Features

### Frontend
- 🌌 Dark theme with animated floating gradient orbs
- ✨ Scroll reveal animations on all sections
- 📱 Fully responsive (mobile, tablet, desktop)
- 🎨 Canva brand colors (purple, teal, pink gradients)
- 🔢 Animated stat counters
- 🍔 Mobile hamburger menu

### Backend (Client-side)
- 📧 Newsletter email signup with validation
- 📝 Contact form with modal
- 📊 Client-side analytics tracking
- 🍪 Cookie consent banner
- ❓ FAQ accordion
- 🔔 Toast notifications
- 💾 Local storage database
- 📈 Console analytics dashboard (`CanvaProStats()`)

### Sections
| Section | Description |
|---------|-------------|
| Hero | Gradient text, CTA, animated counters |
| Trusted By | Company logos bar |
| Features | 6 feature cards with hover effects |
| Magic Studio | AI tools showcase |
| Templates | 8 colorful template categories |
| Pricing | 3-tier pricing comparison |
| Testimonials | Customer reviews |
| FAQ | Expandable accordion |
| CTA | Email capture form |
| Footer | Newsletter, social links, navigation |

## 🚀 Tech Stack

- **HTML5** — Semantic markup
- **CSS3** — Custom properties, Grid, Flexbox, animations
- **JavaScript** — Vanilla ES6+ modules
- **Font Awesome** — Icons
- **Google Fonts** — Inter typeface

## 📂 Project Structure

```
canva-pro-landing/
├── index.html          # Main landing page
├── css/
│   └── components.css  # Forms, modals, toasts, FAQ styles
├── js/
│   └── app.js          # Backend module (forms, analytics, storage)
└── README.md
```

## 🛠️ Development

Just open `index.html` in your browser — no build tools needed!

## 📊 Analytics

Open your browser console and run:
```js
CanvaProStats()
```

This shows subscriber count, contact submissions, trial signups, and recent events.
